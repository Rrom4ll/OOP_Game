# กติกาเกม

## รูปแบบการเล่น

ผู้เล่นเริ่มตัวเปล่าในดันเจี้ยนชั้น 1 สำรวจหาอุปกรณ์และกุญแจ เลือกสู้หรือเดินเลี่ยงมอน แล้วลงชั้น 2 เพื่อไปถึงทางออก

- Java บน Terminal ภาพ ASCII มุมมองบุคคลที่หนึ่ง
- แผนที่ ของ มอน ประตู และบันไดกำหนดตำแหน่งตายตัว
- มอนยืนอยู่กับที่ ไม่มีการไล่ตามหรือเกิดใหม่
- มีสองชั้น บันไดลงอย่างเดียว กลับชั้นก่อนหน้าไม่ได้
- ข้อความทุกส่วนในเกมเป็นภาษาอังกฤษ

## คำสั่ง

ทุกคำสั่งกด Enter ยอมรับตัวพิมพ์เล็ก/ใหญ่และตัดช่องว่างหัวท้าย

| คำสั่ง | ผล |
|---|---|
| W | เดินหน้าหนึ่งช่อง หรือโจมตีมอนที่อยู่ติดกันตรงหน้า |
| A | หันซ้าย 90 องศา |
| D | หันขวา 90 องศา |
| I | เปิด Inventory |
| Q | ออกจากโปรแกรม ใช้ได้ทั้งหน้าปกติและ Inventory |

ไม่มีการเดินถอยหรือเดินด้านข้าง คำสั่งว่าง/ไม่ถูกต้องไม่เปลี่ยนโลกเกม เมื่อ input สิ้นสุดให้ออกโปรแกรม

## การเดินและการตี

เมื่อกด W ให้ตรวจช่องติดกันตรงหน้าตามลำดับนี้:

1. มีมอนมีชีวิต: โจมตีหนึ่งครั้งแล้วจบคำสั่ง ผู้เล่นอยู่ช่องเดิม
2. เป็นกำแพง/นอกแผนที่: อยู่ช่องเดิม
3. เป็นประตูล็อก: ตรวจ matching key แล้วเปิดตามกติกาประตู
4. เป็นช่องที่ผ่านได้: เดินหนึ่งช่อง แล้วตรวจของ บันได หรือทางออกบนช่องนั้น

การโจมตีไม่ทำให้เดินต่อ แม้มอนตาย หลังช่องว่างแล้วต้องกด W ครั้งใหม่จึงเดินเข้าไป มอนที่อยู่ข้างตัว ด้านหลัง หรือไกลออกไปไม่ใช่เป้าหมาย

## การต่อสู้

1. ผู้เล่นโจมตีก่อน ลด HP มอนและแสดงค่าที่เหลือ
2. ถ้ามอนตาย ให้ EXP ครั้งเดียว นำมอนออกจากช่อง และไม่สวนกลับ
3. ถ้ามอนรอด มันสวนหนึ่งครั้ง ลดดาเมจด้วยเกราะที่สวม
4. ถ้า HP ผู้เล่นเป็น 0 ให้ Game Over
5. ผู้เล่นอยู่ตำแหน่งเดิมตลอดคำสั่งนี้

ผู้เล่นหนีได้โดยหันแล้วเดินไปทางที่ผ่านได้ มอนไม่ตาม การเปิดกระเป๋า ใช้ของ หัน หรือเดินที่อื่นไม่ทำให้มอนโจมตีเอง

```text
You hit Goblin for 7 damage.
Goblin HP: 5/12
Goblin hits you for 3 damage.
Your HP: 17/20
```

เมื่อ Goblin เหลือ 5 HP การโจมตีถัดไปหักจริง 5:

```text
You hit Goblin for 5 damage.
Goblin HP: 0/12
Goblin defeated. You gained 5 EXP.
Your HP: 17/20
```

## Inventory และอุปกรณ์

- เดินถึงของแล้วเก็บเข้ากระเป๋าอัตโนมัติ ของหายจากด่านและไม่เก็บซ้ำ
- เริ่มกระเป๋าว่าง ไม่มีอาวุธหรือเกราะที่สวม
- I แสดงรายการของพร้อมหมายเลข เลือก Weapon/Armor เพื่อ Equip หรือ Potion เพื่อ Use
- เลือก Key จะแสดงรายละเอียด กุญแจใช้เมื่อเดินชนประตู ไม่ต้อง Equip
- 0 กลับหน้าปกติ Q ออกจากเกม การเลือกผิดไม่ใช้ของ
- มีช่องอาวุธหนึ่งช่องและเกราะหนึ่งช่อง เปลี่ยนชิ้นแล้วแทนชิ้นเดิม ไม่บวกโบนัสซ้ำ
- มีดาบในกระเป๋าแต่ยังไม่ Equip ไม่เพิ่ม ATK และไม่แสดงภาพดาบ
- เกราะลดดาเมจเฉพาะเมื่อ Equip
- ใช้ยาฟื้น HP ไม่เกิน Max HP ยาหายหนึ่งชิ้นเมื่อฟื้นสำเร็จ เลือดเต็มแล้วไม่เสียยา
- กระเป๋าไม่จำกัดจำนวนในรุ่นแรก ไอเทมแต่ละชิ้นเป็นออบเจ็กต์แยกกัน

## ประตูและชั้นดันเจี้ยน

- ประตูตรวจรหัสกุญแจให้ตรงกัน เช่น Copper Door กับ Copper Key ใช้ keyId เดียวกัน
- ไม่มีกุญแจที่ตรงกันเปิดไม่ได้และไม่เสียของ
- เปิดสำเร็จใช้กุญแจหนึ่งชิ้น ประตูเปิดถาวร และผู้เล่นยังอยู่ช่องเดิม W ครั้งต่อไปจึงเดินผ่าน
- ก่อนลงบันไดแสดงคำเตือนเมื่อผู้เล่นอยู่หน้าบันได: `Stairs down. You cannot return.`
- เดินเข้าช่องบันไดแล้วลงทันที ส่งต่อ HP, Level, EXP, Inventory และอุปกรณ์ที่สวมไปจุดเริ่มชั้น 2
- เดินถึงทางออกท้ายชั้น 2 จึงชนะ ไม่บังคับฆ่ามอนทุกตัว
- หลังชนะ/แพ้ มีเมนู R เริ่มใหม่และ Q ออกเกม เริ่มใหม่แล้วโลกและผู้เล่นกลับสภาพเริ่มต้น

## ค่าตั้งต้นสำหรับพัฒนา

ตารางนี้ใช้ให้ทั้งสองส่วนทำงานร่วมกันได้ตั้งแต่รอบแรก ปรับสมดุลภายหลังได้โดยแก้ที่นี่และค่าที่สร้างออบเจ็กต์ให้ตรงกัน

| รายการ | ค่า |
|---|---|
| Player | Level 1, HP 20/20, base ATK 2, DEF 0, EXP 0 |
| Iron Sword | ATK +5 |
| Leather Armor | DEF +2 |
| Healing Potion | Heal 10 HP |
| Goblin | HP 12, ATK 5, EXP 5 |
| Copper Key / Copper Door | keyId = `copper` |
| Level Up | Max HP +5, ATK +1, Current HP คงเดิม |
| EXP ที่ต้องใช้ | `10 + 5 × (Level - 1)` เช่น 10, 15, 20 |

```text
ATK = 2 + (Level - 1) + equippedWeaponBonus
DEF = equippedArmorBonus หรือ 0 เมื่อไม่สวม
ดาเมจมอนสวน = max(1, enemyATK - DEF)
HP ที่ถูกหักจริง = min(ดาเมจที่คำนวณได้, HP เป้าหมาย)
```

attack() คืน HP ที่หักจริงเพื่อใช้ใน log ไม่มีการสุ่มดาเมจ ถ้าฝ่ายโจมตีหรือเป้าหมายตายแล้วให้คืน 0 โดยไม่เปลี่ยนข้อมูล

EXP ใน HUD เป็น EXP ของ Level ปัจจุบัน เมื่อครบเกณฑ์หักค่าเกณฑ์นั้นแล้วเพิ่ม Level เก็บส่วนเกินต่อและตรวจซ้ำได้หลายระดับ โดยไม่เพิ่ม Current HP

## ข้อกำหนดของด่านและหน้าจอ

- ด่านมีเส้นทางที่เล่นจบได้ วางดาบให้เข้าถึงได้ก่อนการต่อสู้ที่จำเป็น
- กุญแจต้องไม่อยู่หลังประตูที่ต้องใช้กุญแจดอกนั้น ของ มอน ประตู บันได และทางออกไม่วางทับช่องเดียวกัน
- ช่องมอนที่ตายเดินผ่านได้ ไม่มีของดรอปในรุ่นแรก
- STATUS อยู่ซ้ายบน ฉากอยู่กลาง CONTROLS อยู่ขวา และมีชื่อ/HP มอนตรงหน้า
- log แสดงการโจมตี HP มอน การสวน HP ผู้เล่น และ Level Up โดยไม่ทำให้กรอบจอเลื่อน
- เฟรมหลัก 120×40 ช่อง โหมด 160×50 ทำหลังเฟรมหลักอ่านได้ครบ
- ไม่มี random map, save/load, multiplayer, เวทมนตร์ ร้านค้า หรือระบบลอบเร้นในงานรุ่นแรก

ผลที่ต้องลองร่วมกัน: เดิน/ชนกำแพง, เปิดประตูด้วยกุญแจถูกและผิด, Equip/ใช้ยา, ตีมอนรอด/ตาย, หันเดินหนี, Level Up ไม่ Heal, ลงชั้นสอง, ชนะ/แพ้ และเริ่มใหม่
