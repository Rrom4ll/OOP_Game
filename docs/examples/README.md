# ตัวอย่างภาพ ASCII สำหรับสื่อสารแบบเกม

เป็นอาร์ตร่างข้อความที่สร้างด้วยความช่วยเหลือจาก AI เพื่ออธิบายโปรเจกต์ ไม่ใช่ผลการรันเกมจริง ไม่ใช่อาร์ตจาก Greed & Darkness และยังไม่ถือว่าเลือกเป็น production assets

| ไฟล์ | ขนาด | อธิบาย |
|---|---|---|
| [มือเปล่า](gameplay-unarmed-120x40.txt) | 120 × 40 | ไม่มีภาพดาบ ATK พื้นฐาน และ Goblin HP เต็ม |
| [สวมอุปกรณ์](gameplay-equipped-120x40.txt) | 120 × 40 | ดาบ/เกราะ Equip แล้ว Goblin เหลือ 5/12 หลังถูกตี |
| [โหมดละเอียด](gameplay-equipped-160x50.txt) | 160 × 50 | ตัวอย่างจัดพื้นที่เมื่อเพิ่มคอลัมน์/แถว |
| [Goblin](enemy-goblin-24x18.txt) | 24 × 18 | sprite ศัตรูต้นฉบับ |
| [Sword](weapon-sword-18x20.txt) | 18 × 20 | ภาพดาบด้านหน้าที่แสดงหลัง Equip |
| [Door](door-22x16.txt) | 22 × 16 | ประตูตัวอย่าง |

ขนาดเป็นคอลัมน์ × แถว ทุกช่องเป็น printable ASCII กับ space ไม่มี tab เปิดด้วยฟอนต์ monospace และปิด word wrap ตัวอย่างจริงใน Terminal ต้องทดลองขนาดฟอนต์อีกครั้ง

ช่องว่าง sprite เสนอให้เป็นโปร่งใสเมื่อซ้อนภาพ ส่วนช่องว่างในฉากเป็นสีพื้น ข้อตกลงนี้ต้องใช้ตรงกันใน renderer กับส่วน Terminal

การออกแบบ sprite บางชิ้นปรับจากขนาดร่าง ART_GUIDE เล็กน้อยเพื่อให้รูปทรงอ่านออก ขนาดยังเป็นตัวอย่างและไม่ใช่สัญญาไฟล์ที่ล็อกแล้ว
