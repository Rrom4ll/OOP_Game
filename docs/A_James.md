# A (James) — โลกเกม หน้าจอ และการรวมงาน

Branch: `feat/world-view`

James รับผิดชอบแผนที่ การเดิน ประตู กุญแจ บันได ภาพ ASCII การรับคำสั่ง หน้าจอทั้งหมด และการเชื่อมระบบของ Jezz ให้เป็นเกมที่เล่นได้ ดูกติกาใน [GAME_DESIGN](GAME_DESIGN.md) และภาพรวมใน [PROJECT_BRIEF](PROJECT_BRIEF.md)

## 1. Branch ที่ใช้

| Branch | เจ้าของ | หน้าที่ |
|---|---|---|
| `main` | ใช้ร่วมกัน โดย James ประสานการรวม | เก็บเวอร์ชันที่รวมระบบและรันได้ |

## 3. งานที่ต้องทำโดยละเอียด

### 3.1 เริ่มและควบคุมเกม

- ให้ Main เรียก Game เป็นจุดเริ่มเดียว
- สร้างสถานะเริ่มรอบใหม่ ผู้เล่นเริ่มตัวเปล่า ด่านและมอนกลับไปตำแหน่งคงที่
- รับ W/A/D/I ผ่าน TerminalDisplay แล้วส่งต่อไปยังส่วนที่เกี่ยวข้อง
- เมื่อ HP เป็นศูนย์ให้ Game Over และไม่ประมวลผลการโจมตีต่อ
- เชื่อมจุดจบเกมตามเงื่อนไขที่ตกลง และมีวิธีเริ่มใหม่หรือออกเกมที่แสดงคำแนะนำเป็นอังกฤษ

### 3.2 แผนที่ การเดิน และทิศ

- ออกแบบสองชั้น กำหนดช่องกำแพง ทางเดิน ของ มอน ประตู และบันไดตายตัว
- ใช้พิกัด x เพิ่มไปขวา y เพิ่มลงล่าง อาร์เรย์เข้าถึงด้วย `[y][x]`
- A หันซ้ายและ D หันขวา 90 องศา โดยตำแหน่งไม่เปลี่ยน
- W เดินครั้งละหนึ่งช่องเมื่อตรงหน้าเป็นทางที่ผ่านได้ ไม่เดินทะลุกำแพง/ขอบแผนที่/ประตูปิด/มอนมีชีวิต
- อ่านและเปลี่ยนตำแหน่ง/ทิศผ่านเมธอดของ Player ที่ Jezz เตรียม ไม่แก้ field ของ Player โดยตรง

### 3.3 เชื่อมการต่อสู้

```text
รับ W -> ตรวจช่องติดกันตรงหน้า
       -> มีมอนมีชีวิต: เรียก Player.attack(enemy)
          -> มอนตาย: ให้ EXP ครั้งเดียวและนำออกจากช่องที่ขวาง
          -> มอนรอด: เรียก Enemy.attack(player) หนึ่งครั้ง
       -> แสดงผล แล้วจบคำสั่งโดยอยู่ช่องเดิม
```

- ใช้ระบบคำนวณของ Jezz ไม่เขียนสูตรโจมตีอีกชุดใน Game
- มอนด้านข้าง ด้านหลัง หรืออยู่ไกลเกินหนึ่งช่องไม่ใช่เป้าหมายของ W
- การโจมตีไม่ขยับผู้เล่น รวมถึงครั้งที่ฆ่ามอนตาย W ครั้งถัดไปจึงเดินเข้าช่องที่ว่างได้
- แสดงชื่อมอน ดาเมจ HP มอนคงเหลือ และ HP ผู้เล่น มอนตายต้องไม่สวนและไม่ให้ EXP ซ้ำ
- หันแล้วเดินหนีได้เมื่อมีทาง มอนอยู่ตำแหน่งเดิม

### 3.4 กุญแจ ประตู ของ และบันได

- วางของตามจุดที่ออกแบบ เมื่อเก็บสำเร็จให้เรียก Player.addItem(item) และนำของออกจากด่าน
- สร้าง Key จาก Item ของ Jezz ตรวจ matching key ใน Door จากรายการของที่ Player ส่งให้
- ให้ Jezz เตรียมเมธอดจัดการไอเทมทั่วไป การจับคู่รหัสกุญแจกับประตูอยู่ในส่วนของ James
- ไม่มีกุญแจที่ตรงกันให้แจ้ง เช่น `Locked. Requires Copper Key.`
- เปิดได้แล้วคงสถานะเปิด การหักกุญแจและการเดินผ่านในคำสั่งเปิดครั้งเดียวกันรอตกลงตาม GAME_DESIGN
- เชื่อมบันไดจากชั้น 1 ลงชั้น 2 กลับขึ้นไม่ได้ และย้ายไปจุดเริ่มที่กำหนด
- วางเส้นทางให้หากุญแจและของจำเป็นได้ก่อนลงชั้นถัดไป

### 3.5 ภาพ ASCII และหน้าจอ

- สร้างภาพบุคคลที่หนึ่งตามตำแหน่งและทิศ เริ่มด้วยทางตรง ทางตัน ทางแยก และประตู
- วาดเฉพาะสิ่งที่มองเห็น ไม่ให้มอนหรือของปรากฏทะลุกำแพง/ประตูปิด
- แสดง STATUS ซ้ายบน ฉากตรงกลาง CONTROLS ในกรอบ และชื่อ/HP ของมอนตรงหน้า
- แสดงภาพดาบเฉพาะเมื่อ Player มี equippedWeapon การมีดาบในกระเป๋าอย่างเดียวยังไม่แสดง
- แสดง log ให้พอดีกรอบ แม้เกิดฆ่ามอน ได้ EXP และ Level Up ในคำสั่งเดียวกัน
- เริ่มจาก 120×40 ช่อง แล้วปรับโหมด 160×50 ตามผลทดลองฟอนต์และขนาด Terminal
- renderer มีหน้าที่อ่านข้อมูลและสร้างภาพ ไม่ลด HP ไม่ให้ EXP และไม่เปิดประตู

### 3.6 หน้า Inventory และการรับคำสั่ง

- I เปิดรายการของ แสดงชื่อ รายละเอียด จำนวนที่เกี่ยวข้อง และสถานะ Equip
- รับการเลือกแล้วเรียก equipWeapon/equipArmor/usePotion ของ Jezz
- แสดงค่าพลังใหม่หลัง Equip/Use โดยอ่านจาก Player ไม่คำนวณโบนัสซ้ำใน UI
- ใช้ Scanner/การรับหนึ่งบรรทัดแล้ว Enter จัดการคำสั่งว่าง คำสั่งผิด และ EOF
- ทุกข้อความที่ผู้เล่นเห็นเป็นอังกฤษ

## 5. ข้อมูลที่ต้องรับจาก Jezz

ตกลงชื่อและชนิดคืนค่าก่อนเขียนเชื่อม ตารางนี้เป็นสัญญาที่เสนอ ยังไม่ใช่โค้ดที่มีอยู่แล้ว

| เมธอด/ข้อมูลจาก Jezz | James ใช้ทำอะไร |
|---|---|
| getX(), getY(), getDirection(), moveTo(x,y), setDirection(direction) | ควบคุมการเดิน/หันและวาดภาพ |
| getHp(), getMaxHp(), getAttack(), getDefense(), getExp(), getLevel() | แสดง STATUS และตรวจจบเกม |
| Player.attack(enemy), Enemy.attack(player) | เรียกผลโจมตีตามลำดับใน Game โดยเมธอดเหล่านี้ไม่ย้ายตำแหน่ง |
| Enemy.isAlive(), getHp(), getMaxHp(), getExpReward() | ตรวจตาย แสดง HP และให้ EXP ครั้งเดียว |
| Player.gainExp(amount) | เพิ่ม EXP หลัง Game ยืนยันการฆ่า |
| getItems(), addItem(item), removeItem(item) | แสดงกระเป๋า เก็บของ และใช้กับกุญแจตามกติกาที่เลือก |
| equipWeapon(weapon), equipArmor(armor), usePotion(potion) | เรียกจากหน้า Inventory |
| equipped weapon/armor และ Item.getDescription() | วาดดาบและแสดงข้อมูลของ |

Jezz ดูแล Player, Enemy และ Item ถ้าต้องการเมธอดเพิ่มให้ตกลงก่อน ส่วน Key/Door และการจับคู่กุญแจ James ดูแล

## 7. Git flow ของ James

ใช้ repo ของตนเองในเครื่อง ไม่แก้ working directory เดียวกับ Jezz ก่อนสลับ branch ให้ commit งานค้างใน branch เจ้าของงานก่อน

### เข้า branch ครั้งแรกหลัง clone

```bash
git fetch origin
git switch --track origin/feat/world-view
```

ถ้ามี local branch อยู่แล้วหรือกลับมาทำงานครั้งต่อไป ใช้ `git switch feat/world-view`

### บันทึกและส่งงานของตนเอง

ตัวอย่างรอบเดินสำรวจ เลือก git add เฉพาะไฟล์ที่สร้างหรือแก้จริง:

```bash
git add src/Main.java src/Game.java src/Dungeon.java
git commit -m "feat: add dungeon movement and turning"
git push -u origin feat/world-view
```

### รับงานที่รวมแล้วกลับเข้า branch

```bash
git fetch origin
git switch feat/world-view
git merge origin/main
```

### รวมงานลง main

เมื่อ Jezz แจ้งว่ารอบนั้นพร้อมและ push แล้ว ให้รวมส่วนที่ต้องใช้ก่อน:

```bash
git fetch origin
git switch main
git pull --ff-only origin main
git merge --no-ff origin/feat/player-combat
```

ถ้า branch ของ James ต้องใช้เมธอดใหม่จาก Jezz ให้นำ main ที่รวม Jezz แล้วเข้า feat/world-view ทำส่วนเชื่อมให้เสร็จ และ push feat/world-view ก่อน จากนั้นจึงรวมงาน James:

```bash
git switch feat/world-view
git merge main
```

ทำส่วนเชื่อม/แก้ conflict ตามไฟล์ที่เกี่ยวข้อง แล้ว commit และ push branch ตัวเอง จากนั้น:

```bash
git switch main
git merge --no-ff origin/feat/world-view
```

ลองรันผลรวมของรอบนั้น ถ้ามีปัญหาให้แก้ใน branch เจ้าของงานแล้วรวมใหม่ เมื่อพร้อมจึงส่ง main:

```bash
git push origin main
```

แจ้ง Jezz ให้นำ origin/main ล่าสุดเข้า branch ของเขา แล้วเริ่มรอบถัดไป ใช้สอง branch เดิมตลอด ไม่ต้องลบแล้วสร้างใหม่ระหว่างรอบ

## 8. ผลที่งาน James ต้องทำได้

- เดินและหันได้ ภาพตรงกับตำแหน่ง ไม่มีการเดินทะลุสิ่งขวาง
- W ตีเฉพาะมอนตรงหน้าติดกัน และไม่ขยับแม้ฆ่าได้
- เปิด Inventory แล้วเลือกใช้/สวมของได้จากเมธอดของ Jezz
- ประตู กุญแจ และบันไดทำงานตามกติกาที่เลือก
- STATUS, CONTROLS, HP มอน และ log เป็นอังกฤษ อ่านได้ ไม่ล้นกรอบ
- ลงชั้นสองได้และไม่ย้อนขึ้น เริ่มใหม่แล้วโลกกลับสภาพเริ่มต้น

คำสั่งพื้นฐานเมื่อมี src/*.java ครบตามโครงสร้างและยังไม่ใช้ package:

```powershell
javac -encoding UTF-8 -d build src/*.java
java -cp build Main
```

ฐาน main มี Main.java ที่ compile/run ได้แล้ว ใช้ branch ของตนพัฒนาคลาสระบบเกมตามรอบงานข้างต้น
