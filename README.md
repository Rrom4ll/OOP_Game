# OOP_Game

เกมสำรวจดันเจี้ยนมุมมองบุคคลที่หนึ่ง เขียนด้วย Java และแสดงภาพ ASCII บน Terminal ผู้เล่นสำรวจ เก็บกุญแจ ใช้อาวุธ ต่อสู้ และเปิดทางออก

สถานะวันที่ 18 พฤศจิกายน 2026: มีโครงเริ่มต้น `src/Main.java` ที่ compile/run ได้และเอกสารงานครบ ระบบดันเจี้ยนจะพัฒนาต่อใน branch ของ James และ Jezz

## เริ่มรันโปรเจกต์

ต้องมี JDK ที่ใช้คำสั่ง java และ javac ได้ เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรัน:

```powershell
javac -encoding UTF-8 -d build src/*.java
java -cp build Main
```

ผลของโครงเริ่มต้น:

```text
OOP_Game
Java Terminal Dungeon Crawler
The dungeon is under construction.
```

ตรวจคำสั่งนี้ด้วย JDK 26.0.2.1 โครงเริ่มต้นไม่ใช้ไลบรารีภายนอก ไฟล์ที่ compile แล้วอยู่ใน build/ และไม่เก็บใน Git

## Branch สำหรับพัฒนา

| Branch | ผู้รับผิดชอบ | ใช้ทำอะไร |
|---|---|---|
| main | James ประสานการรวม | ฐานที่รวมงานแล้วและรันได้ |
| feat/world-view | A (James) | โลกเกม หน้าจอ และการเชื่อมระบบ |
| feat/player-combat | B (Jezz) | ผู้เล่น ไอเทม มอน ต่อสู้ และ EXP/Level |

หลัง clone ให้ fetch แล้วเข้า branch ของตน เช่น:

```bash
git fetch origin
git switch feat/world-view
```

Jezz ใช้ git switch feat/player-combat ใช้ branch เดิมทำงานต่อและรวมเข้า main ตาม flow ในเอกสารรายคน

## ข้อตกลงตั้งต้น

- สมาชิกเป็นผู้ออกแบบและเขียนโค้ดหลักด้วยตนเอง และอธิบายงานที่รับผิดชอบได้
- รันบน Terminal ใช้คำสั่งแล้วกด Enter เดินทีละช่อง หันทีละ 90 องศา
- เกมเป็นภาษาอังกฤษทั้งหมด เริ่มตัวเปล่า A/D หัน W เดินหน้า หรือโจมตีมอนที่อยู่ตรงหน้าโดยไม่ขยับตัว
- มอนอยู่ประจำช่อง ตัวที่ถูกฆ่าไม่สวนกลับ แสดง HP มอนที่เหลือทุกครั้งที่ตี ใช้ของ/สวมอุปกรณ์ผ่าน Inventory
- ออกแบบสองชั้นแบบตำแหน่งคงที่ ลงได้อย่างเดียว Level Up เพิ่ม max HP และ ATK โดยไม่ฟื้น current HP
- ใช้ Java standard library เป็นฐาน ทดลองภาพมุมมองบุคคลที่หนึ่งก่อนขยายระบบ
- ตั้งเป้าภาพ 120 × 40 ช่อง และโหมดละเอียด 160 × 50 ช่อง รวม HUD โดยต้องลองกับเครื่องของสมาชิก
- ใช้ main กับ feat/world-view ของ James และ feat/player-combat ของ Jezz รวมงานที่พร้อมเป็นช่วง แล้วนำ main กลับเข้า branch เดิม

## ประชุมเริ่มต้น

1. เลือก JDK รุ่นเดียวกันและวิธี compile/run ร่วมกัน
2. เทียบความรู้ที่ใช้กับเอกสารเรียนใน COURSE_SCOPE
3. ตกลงพิกัด ทิศ constructor ของ Item และเมธอดที่ James/Jezz เรียกใช้ร่วมกัน
4. วาดแผนที่หนึ่งด่านและเส้นทางเล่นจนชนะบนกระดาษ
5. เริ่มจาก Main.java บนฐาน main แล้วเข้า branch ของตนตามเอกสารรายคน

ตอนนี้ src/ มี Main.java เป็นจุดเริ่มต้น ส่วนคลาสระบบเกมและ assets/ จะเพิ่มตามรอบงานที่แบ่งไว้
